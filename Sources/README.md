# Fontes do projeto

Este diretório contém materiais de referência e projetos-fonte auxiliares. Os
projetos `cachy-chroot/` e `cachyos-bootloader-switcher/` são repositórios
independentes; suas implementações, licenças e limitações não são contratos
automáticos do crate principal.

As referências externas anotadas, organizadas por assunto e com links para as
fontes originais, estão em [`references/README.md`](references/README.md).

Não use este material como autorização para executar reparos. Confirme a
configuração real do sistema e siga as regras de segurança do `AGENTS.md`.
